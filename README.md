# CoverFit

Outpaint EPUB book covers to a target aspect ratio — fully in your browser.

**Live page: https://relorer.github.io/CoverFit/**

- Nothing is uploaded anywhere: all processing runs locally

## Development

```sh
npm run dev
npm run check
npm run build
```

## A note on how this project is made

This project is developed mostly with the help of small local models running on a 12 GB GPU, purely as an experiment
